# Approved three-project showcase pilot

`node --import tsx examples/xhs-pilot/showcase-plans.ts` builds six rendering manifests from the exact approved scripts, actual local narration receipts and source assets under `work/xhs-pilot-v1/production`. It skips unfinished narration rather than fabricating it. These are deliberately project-specific editorial shot choices for this approved pilot, not a claimed automatic general planner. The renderer/contract/crop machinery is reusable.

The local production directories are not distributed: private voice material, third-party screenshots and movies remain subject to their own provenance/rights. Source script approval does not authorize publication. The script retains the existing narration bytes and approved wording; external captions/annotations describe official demos and mechanisms, not a fresh target-project run.
