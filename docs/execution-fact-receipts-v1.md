# Exact preview fact attribution

`explanation narrative-caption-review --task <preview-task> --spec <receipt.json> --data <state> --out <new-output>` records a caller-authored `fact-review-receipt/1.0` against the actual exported `fact-review/current-execution-packet.json`. The command checks the full preview closure and every required review item before writing an immutable attribution task. Exact receipt bytes, normalized receipt, packet and editable preview are exported together. Receipt data is never executable. This command does not call a model or provide independent semantic, listening, owner or production approval.

Use `narrative-caption-review-status --task <attribution-task> --data <state>` to recheck it and `narrative-caption-review-export --task <attribution-task> --data <state> --out <new-output>` to reexport it. `explanation next` provides these steps. The original preview's review status stays pending; the attribution has its own unresolved/supported item status. Reviewer identity is supplied by the caller and is not authenticated. A receipt for an old execution cannot be attached to changed source/plan/visual/audio/movie content. Historical immutable receipts remain valid for their original task.
