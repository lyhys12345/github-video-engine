# Source-bound causal operation animation v1

Animation schema 1.2 adds one reusable capability: an authored, continuously sampled input→tool→output operation view. It is separate from evidence schema versions and does not change animation 1.0 or independent-flow animation 1.1. The author selects only an existing operation ID and four fractional phase times (`start`, `arrive`, `processed`, `end`) for every selected Story shot. Input, output, tool, operation claims and displayed labels derive from the exact pinned, author-curated evidence graph. This relation is not machine-certified semantic truth.

Supported operations are narrowly `match-route`, `send-response`, `segment` and `document-transform`, each with one distinct input/output and one tool actor, no operation parameters. Unknown operations, arbitrary extra geometry/claims, bad/zero-frame phase order, missing shot claims and unsupported object kinds are rejected. `extract` and `composite` are explicitly unsupported: their existing shorthand graph input cannot faithfully convey all image/mask operands. They are not silently rendered as one-input transformations. Independent document-flow evidence remains on its separate established adapter. Labels require supported Chinese/Latin font characters and conservative lengths; actors/input/output retain their source-graph identities.

The input stays in its own position with the same identity and artwork. An independent illustrative signal travels continuously on a Bézier path, eases to a stop, activates a tool state, then travels toward the output. It is not the input object, actual payload, observed message or measured latency. Route matching activates an already visible handler; it does not create that handler or turn the request into a response. Derived output is separately constructed by a progressive reveal, while the source remains. Segment shows an independently identified illustrative mask beside the retained source image. Those synthetic silhouette pixels are not an actual model prediction or real photograph result. No target code or example runs.

The trusted native stage occupies the full 720×1280 source frame, composed 1:1 without crop or a small diagnostic window. Large objects and their associated moving signal carry the explanation. Concise operation/experiment/pending text replaces the former multi-line explanation panel on supported scenes. The top 76 pixels and bottom 160 pixels are reserved for trusted provenance labels and burned full-narration subtitles; source content remains above 1120. A separately overlaid `visualContext` is rejected on native causal source scenes to prevent hiding either explanation. Existing Chinese gap cards and all prior non-native layouts are retained. Every display string, operation/phase/input/output/actor mapping, native layout, full source/child closure, recording, captions and actual movie digest enters the current pending execution facts packet. No semantic or listening approval is inherited.

Generic label wrapping measures Han characters as two units and ASCII as one, keeping Latin/code tokens intact. Actual first frames exposed split `GET /hello`/`PocketBase` tokens and a glow ring close to an output label. Both were corrected generically, with earlier source/voiced movies and frame PNGs preserved rather than overwritten. Native input/output rings now leave the label area clear. The stage rectangle declares the full area above the subtitle boundary rather than claiming a tighter unsupported glyph boundary.

The rembg second scene is a closing replay of the same supported segment operation, not a second new mechanism. Its authored visual scope explicitly excludes composition; the old full closing narration is retained, and other source-backed stages remain explicit omissions. This exercise does not claim complete rembg processing coverage. All original full-project gap scenes remain silent and visible; unselected supported scenes are listed in coverage and the selected export page. Original long previews remain byte-identical. No new TTS/model calls, paid tools, target execution, full regression, Judge or formal film.

Final local data/evidence roots are `work/causal-operation-checks/pocketbase-final` and `rembg-final`. Their `preview.html` opens the selected voiced movie and editable source/animation/audio/caption/current-facts export. `plan.json`, per-scene Story/animation files, source-progress records, selection, actual result, full media verification and input/process/output frame PNGs preserve authorship and execution. Earlier `pocketbase`/`rembg` and `*-labels` roots preserve the observed layout defects and intermediate fixes. Large media/local data are ignored and not included in this code commit.

Verification covers exact stream/frame counts and full FFmpeg decode, actual non-silent 48kHz mono AAC, complete decoded PCM byte equality against original long-version recording segments, whole transcript/caption partitions, every silent gap and omitted supported scene, independent semantic object identities, exact visible/voice text in the pending packet, repeat cache reuse and unchanged original long movie hashes. These are technical checks, not natural listening or semantic acceptance. Actual input/process/output frames were inspected for both project classes. The native stage removes the old source thumbnail; it does not prove phone readability.

Typecheck passed. 35 necessary tests passed: 4 causal-operation (including code-token label spans), 5 existing Story animation, 2 existing frame-preview, 21 independent-flow compatibility and 3 selected-reset. Phase-boundary testing exposed an abrupt linear-speed stop and led to fixed smoothstep timing; the test subsequently passed. No broader regression was run.

Known limits: one selected operation per Story shot; separate native source Stories are supported by the existing stage APIs. This experiment does not add mixed causal/legacy shot authoring to the unified complete-run JSON. There is no cross-scene entity persistence, arbitrary branching, multi-input composition, actual repository runtime simulation or measured action/speech word alignment. Natural listening, transcript correctness, semantic causal interpretation, continuous perceptual AV, phone/ordinary-viewer acceptance and final owner acceptance remain pending. This is a technical illustration capability and selected experiment, not a formal film or 90% readiness claim.
