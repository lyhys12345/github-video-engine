# URL-to-preview integration: review contract

This integration is a step toward the owner's requested 90% readiness, not a declaration that the product has reached it. Reviews apply to a frozen candidate and its recorded inputs. Historical reports and the owner's deferred audiovisual review remain unchanged.

## Required observations

1. A public GitHub project is read only; the commit and source bytes are pinned, and project code is not executed. Research assistance must distinguish captured source text from agent-authored conclusions and leave semantic judgment pending.
2. A verified project-bound Story and editable animation produce a real continuous preview. Its provenance and illustrative/reconstructed material remain visible or readily inspectable. Test at least two materially different project mechanisms with actual source evidence.
3. Where speech is present, bind the exact script and audio bytes, measure the audio and preserve it without truncation or unreported speed changes. Identify prototype voices and estimated subtitle timings; technical checks do not certify naturalness or listening.
4. Persist and independently inspect inputs, task status, artifacts and exports; repeat execution and input changes must preserve and correctly distinguish committed results. Exercise interrupted execution, recovery and integrity failure with real evidence or explicitly mark the missing check.
5. Deliver editable source inputs, source references and a truthful handoff; explain the boundaries of automation, provider availability and final owner acceptance.
6. Run appropriate tests and real media inspection. Independent product, reliability and evidence judges and all applicable video-quality, content-facts and security specialists review the same frozen candidate. A missing check, unrun test or unobserved media is not a PASS. Changes after review require a new candidate and affected rechecks.

Actual listening, continuous perceptual audiovisual judgment and final G6 remain pending owner review under the existing explicit deferral. This contract does not authorize paid generation, deployment, publication, execution of target repositories or full production based solely on a preview.
