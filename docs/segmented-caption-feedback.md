The session Agent authors all partitions and recording-relative sample boundaries; the engine does not infer speech alignment. End sample may be `$FULL_RECORDING_SAMPLES` only for the final cue. Text ranges must continuously cover the exact new scene text; sample ranges must be ordered and nonoverlapping (pauses are permitted). Each cue must fit the existing caption layout. Measured speech checkpoint still validates readability duration, complete recording fit, and frame projection before animation.

When an existing scene has segmented captions, replacement partitions are required. Omitting them retains the previous safe rejection. Existing single-whole-cue requests remain compatible. Original author, scene/narration hashes, checkpoint guards and pending review states are preserved. This additive field is also available on `run-revise` edits; its scene-level meaning is one complete replacement partition, not per-shot partial captions.
