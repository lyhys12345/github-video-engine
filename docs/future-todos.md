# Future product ideas

These are deferred ideas, not implemented capabilities or current milestone requirements. Prioritize only when the user decides they are useful.

## Optional reference style profile

Allow users to optionally select and configure reference videos or a reference style profile. Record what was actually observed, source and permissions, and distinguish observations from creative suggestions. Let users inspect and edit the profile. References are inspiration, not instructions to copy shots or assets; inaccessible or unexamined references must not be presented as analyzed. Users may choose to proceed without references. The provider, ingestion and evaluation design is deferred.

## Natural-language revision intent to edit plan

In a later optimization, convert feedback such as “make the hook stronger” into a reviewable, editable plan identifying affected scenes, narration, assets and downstream invalidation. Preserve old versions and apply changes through existing task and artifact boundaries. Do not treat an inferred change as a factual claim or approval. Exact interaction and automation are deferred.
