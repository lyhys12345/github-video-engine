# Independent source-backed document flows

This extension expresses independent read/write examples as separate animated lanes. It does not execute parsers, assert shared runtime state, certify semantic truth or promise a lossless round trip. No repository names or project-specific behavior are used by the schemas/compiler/renderer.

## Versioned contracts

Story evidence `schemaVersion: 1.2` adds `flowRelation: independent-source-examples` and2–4 named `flows`. Each flow has `id`, a label up to40characters, ordered `operationIds` and `claimIds`. Only the established code→code `document-transform` operation is allowed, with exactly one tool actor and no parameters. Each flow remains a connected, ordered chain of1–4 operations; at most12 operations exist in total. All operations belong to exactly one flow. Flow claims exactly cover their operation claims. Different flows cannot share semantic objects or dependencies. Node labels are bounded to24characters for readable layouts. Arbitrary DAGs, conditionals, forks/merges and shared-state execution remain unsupported.

Identical input text in two documented examples does not establish shared state. Authors must use separate source-backed example identities and disclose the independence. Sources and exact citation lines still pass the existing read-only capture checks; all source interpretation remains authored and pending independent review.

Animation `schemaVersion: 1.1` selects flows separately in each shot:

```json
{"schemaVersion":"1.1","storyId":"authored-story","shots":[{"shotId":"overview","flows":[{"flowId":"read","steps":[{"operationId":"read-op","start":0.1,"end":0.85}]},{"flowId":"write","steps":[{"operationId":"write-op","start":0.1,"end":0.85}]}]}]}
```

The IDs above are schematic; the Agent must supply actual bound source/Story IDs. Each selected flow retains all its ordered operations, positive nonoverlapping time intervals, and full operation claims in the Story shot. The compiler derives every source/target, label and claim from evidence. Authors cannot inject an arbitrary edge, object, coordinate, executable expression or cross-flow connection. Same on-screen timing is illustrative layout/choreography, not a concurrency claim. Single-flow explanation scenes and multi-flow overviews use the same contract.

The renderer draws real bounded SVG panels with independent labels, nodes, local arrows and moving tokens. Its fixed visible disclaimer states that this is unexecuted source-backed illustration, not concurrency, continuous execution or round-trip verification. Evidence, animation and full provenance are exported. Narrative scenes bind the new adapter `document-independent/1.0`; the existing whole-scene/whole-recording complete profile, subtitles and scene caching remain in use.

Legacy evidence1.0/1.1 and animation1.0 retain their contracts, including rejection of disconnected chains. Independent evidence requires animation1.1, and animation1.1 requires independent evidence1.2. The legacy proposal mapper explicitly retains the old animation shape. Previously exported narrative schemas keep their original adapter enums when their plans do not use the new adapter. No historical media, missing-capability decision or review is rewritten.
