# Selected reset narrated preview v1

The complete narrated compositor already accepted authored Chinese `visualContext`, but only silent layout diagnostics had exercised it. A short voiced check could not honestly use the older short profile: it required same-source continuity bridges and at most six seconds per slice. Complete-profile selection must retain every scene. Neither contract was widened.

The new explicit pair `narrative-selected-reset-selection/1.0` / `narrative-selected-reset-narrated-preview/1.0` selects source scenes at reset boundaries and uses the same complete-recording, caption-safe compositor. It preserves original scene order, at least two supported scenes, every unresolved gap and the existing at-most 300 second total budget. It explicitly records all unselected supported scenes as `omitted-supported-scene`; they are not claimed as produced. The exported page and selected status list those omissions. The lead calls this a SELECTED TECHNICAL PREVIEW. It is not complete-story coverage, automatic model work, fact approval or formal-film authorization. The unified complete run remains unchanged; the session Agent can submit a selected spec through the existing `explanation narrative-caption-preview --task PLAN --spec SPEC --data STATE --out NEW` entry. Users still request edits in prose.

Selected clips require the same exact current narration, trusted imported recording receipt, complete original-speed samples, full authored caption partitions and scene fit as complete previews. No clipping, stretching, truncation, hidden narration gaps or automatic duration extension is introduced. All gaps remain visible, silent and without voice captions. Different scene contexts cannot be grouped into one source-clock continuation; they require reset, so a later context cannot silently disappear. No new context/presentation version was added.

The v1 context layout keeps five concise authored Chinese context lines above a complete uncropped 432×768 source viewport at (144,336), ending at 1104. The reserved subtitle area starts at 1120; captions are burned at 1134/1170/1206. Context glyphs end above 336. Narration plays over those complete source scenes. Every exact context line, source/renderer/layout closure, recording/receipt/transcript/PCM/caption ledger and actual movie digest is bound in the pending execution facts packet. This is provenance/integrity, not verification of semantic correctness. Fine source labels shrink and the Chinese context font is relatively thin; mobile readability is not established.
