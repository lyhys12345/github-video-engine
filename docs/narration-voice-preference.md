# Narration voice preference

The owner selected the previously accepted **local Chen-style approximation** as the default for future videos and does not authorize paid voice platforms. This is a preference for an approximation, not a claim that the original provider's model or weights were obtained.

The unified `explanation run` speech/voice/preview path defaults to the local Windows CUDA adapter using Qwen3-TTS 0.6B Base and the owner's local reference-conditioned profile. It requires the independently installed local Python environment, locked model files and reference audio; when unavailable it fails rather than substituting another voice. Planning and explicitly silent animation remain available. Existing media and recordings are not changed. The earlier [local voice](local-voice-v1.md) experiment used a separate Apple Silicon MLX 1.7B runtime; this Windows adapter does not use that model or claim identical results.

Only when the owner explicitly asks for the alternative, set `GVE_NARRATION_VOICE=windows-huihui` for that particular run. This is the existing Windows voice, not Chen. A low-level explicit Huihui command also remains available for technical testing; neither makes it the default. Never set this variable automatically to bypass the preferred-voice failure.

The owner's approved short Windows audition used Qwen3-TTS 0.6B and the prior rembg reference audio. The profile is an ignored local JSON file at `work/local-chen-profile.json` (or set `GVE_CHEN_PROFILE` to an explicitly owned profile). It contains absolute interpreter/model/reference paths, the full reference transcript and SHA-256/size locks for the exact supported model files. It is not portable without the external runtime, weights and authorized reference audio. No credentials or reference audio belong in Git. The worker uses offline settings and a Python network audit hook; these are not an OS-level network sandbox. The adapter verifies exact text, model/reference/worker hashes and local audio before committing generation and imported-audio artifacts. Per-scene audio and captions remain subject to listening and semantic review; do not describe it as the original Chen model. Full-film quality, cross-device setup and broader runtime support remain unverified.
