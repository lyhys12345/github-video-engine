# Curated research handoff v1

The public durable entry point is `pnpm gve story research-plan --spec examples/story-planner-v1/rea.json --root . --data work/research-state --out work/new-research-plan`. It returns the existing durable story task plus a derived research audit handoff. The story task's portable export retains exact sources, authored story, timeline and citation packet. New story results use result schema 1.1 and commit research-handoff.json in CAS and the portable export. Status/export deterministically rederive and verify it against stored story/source bytes. Historical result schema 1.0 is still read without inventing a missing handoff. The CLI also returns a derived console copy. The command verifies that the committed task binds the same story as the handoff and reports concurrent source changes explicitly. Existing story status/export/diff commands work on its returned task ID. REA and rembg were both actually executed into separate exports under work/rh-rea and work/rh-rembg; this is not automatic discovery of previously unknown projects.

This increment binds existing read-only source capture and curated claims to the complete editable story and estimated frame timeline. It does not automatically read arbitrary repositories and invent a script. The source bytes and citations are validated by the existing capture runtime; the handoff fingerprint binds source hashes, authored story and derived timeline/checklist. Editing any of these creates a different fingerprint. A checklist is an outstanding review requirement, not a claimed semantic verification.

Run `pnpm exec tsx scripts/research-handoff.ts examples/story-planner-v1/rea.json . work/new-rea-handoff.json`, or substitute rembg. The output is an exclusively created JSON file, not an atomic persisted task or approval. Keep the existing `story plan` runtime as the durable planning entry point. This handoff is a supporting audit/export API, not a replacement for that runtime. It does not connect automatic source selection or creative reasoning, and it does not certify that each citation entails its sentence. Such decisions remain agent-authored and independently reviewed.

The handoff contains source hash/byte manifests, claims and their consuming shots, the authored story, compiled estimated timeline and per-shot checks for factual support, input/process/output visibility and inference labeling. Source text is not copied here; preserve the corresponding story task export for portable byte evidence.

Validation: `pnpm exec vitest run tests/research-handoff.test.ts` exercises real REA/rembg fixture reads and deterministic source-bound outputs. No API spending, target execution or media generation occurs.
