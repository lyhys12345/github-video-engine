## 执行约束与当前假设

- 保留 M0 和历史产物，不重置数据库或删掉历史失败记录。
- 单机、无账户、无集群、无网页应用。原生 CLI 是执行器，agent 工作流说明是未来用户入口之一。
- 软件负责确定性契约、持久化、验证和媒体；本聊天的 agent 可提供创意/事实整理，不假装一个本地模板就是调用了 AI 模型。
- 不调用付费 API。优先可验证的本地音频方案/用户素材；不可用时明确阻塞，不能用静音伪装正式旁白完成。
- 对不同仓库只读研究，展示图形讲解/有来源的官方案例，未获授权不执行仓库或权重。
- 工程阶段可以由 judge 在用户委托下决定 G1–G5，但必须保留决定者、候选输入和证据，不能把它记录成用户亲自批准。G6/最终用户验收保持待用户 review。
- 当前语言采用中文、竖屏、约 30–60 秒的 v7 第一版方向作为工程默认，记录为 agent 建议值而非虚构用户逐项确认。无法依用户既有指导解决的重要方向问题才升级用户。
- 两条参考视频链接已尝试读取，尚未取得可观察视频。可以继续实现来源/策划能力，但不可声称已经对齐其具体镜头或声音；进入必须依赖这些内容的质量验收前应再尝试可用读取方式，确实无法获得时如实阻塞或请求必要材料。
