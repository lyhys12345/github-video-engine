# Pending exact-preview evidence worksheet

`explanation narrative-caption-review-prepare --task <selected-preview-task> --data <state> --out <new-directory>` exports a compact evidence worksheet from an already committed and fully verified narrated preview. It does not generate a movie, dispatch a reviewer, record a review or change the preview's pending state.

The package contains exact packet.json, each required claim/authored/execution item in a separate indexed text file, source/claim/context relationships, original source bytes plus numbered display copies, and an escaped static HTML index. Complete unlinked text is explicitly marked as requiring review. Raw source hashes, source URL/context and quoted line ranges are rechecked. Source quotes remain untrusted data; exact provenance and matching quotations do not establish semantic truth.

`receipt-draft.json` deliberately uses `fact-review-receipt-draft/1.0`, reviewer=null, unassigned-unreviewed state and only unverified placeholders. It is NOT a valid fact-review-receipt/1.0 and must not be imported as a real review. The actual receipt schema rejects it. No supported verdict, reviewer identity, listening or approval is generated. A future actual reviewer must perform their own work and author their own receipt. That future review was not started in this slice.

An edited preview produces a different packet/candidate binding and new worksheet. Old worksheets stay attached to their original task; a current source/plan/movie cannot silently inherit an earlier review. Evidence export is replayable after state relocation and retains exact raw source/item bytes. Numbered display copies normalize line breaks only for navigation; raw files remain authoritative.

Actual validation used existing escape-string-regexp and rembg previews on readonly SQLite snapshots/CAS copies. All exported source/item hashes and required coverage were checked, drafts remained unassigned/unverified and were rejected by the actual receipt schema, original previews stayed pending, and the number of attribution tasks did not increase. Changed escape narration yielded different packet/candidate hashes; relocated reexport was byte-identical. See examples/fact-review-preparation-v1/result.json and work/fact-worksheet-v1/actual-verification.json. Friendly local indexes are work/fact-worksheet-v1/{escape,rembg}/open/index.html. No actual semantic review, Judge, full regression, new media, paid API, target execution or production approval occurred.
