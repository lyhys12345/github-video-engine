## Actual execution and verification
- Local production generated all29 approved narration lines. Root independently checked approved text, receipt and WAV hashes, actual PCM metadata and leading/trailing low-energy boundaries. No hidden voice substitution, paid TTS, truncation or playback-speed changes.
- `node work/xhs-pilot-v1/qa-audio.mjs` verified29/29. Spoken-word transcription and listening were not performed.
- `node work/xhs-pilot-v1/qa-final.mjs ID=OUTPUT ...` was run on each actual final output. Every MP4 was independently probed and fully decoded with FFmpeg. For all29 lines, independently decoded original WAV PCM was compared byte-for-byte with its correct position in the composition PCM; only less than one frame of zero alignment padding was allowed.
- `node work/xhs-pilot-v1/decode-review.mjs ID=OUTPUT ...` decoded the final MP4s themselves. The independent reviewer inspected selected actual decoded PNGs and bound reports to each MP4 hash. These are not renderStill files presented as final media.
- Directed implementation checks actually executed: `pnpm exec vitest run tests/showcase-reel.test.ts tests/approved-reel.test.ts`:13 passed; `pnpm exec tsc --noEmit`:exit0. The builder's actual execution excerpt is preserved. No full regression was run.
