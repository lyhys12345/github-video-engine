# RSI public local speech contract

Baseline: 3e47abc547b307850f6577cc6939edb79987ac65. User authorizes a free, private-asset-free local voice path for new users, independent review and repairs, GitHub push and Google Drive handoff. Formal project video generation still requires exact owner script/storyboard approval. No paid provider, target repository execution or automatic publication.

## Acceptance

V1. Explicit public preset provider, separate from owner Anna/Chen. Publicly available model and speaker assets with authoritative code/model license sources, immutable model revision and file hashes, reproducible bounded setup. Never download private recordings or upload voice/model/profile assets. Installation is explicit; synthesis does not implicitly download or call remote TTS. Licensing observations describe published upstream terms, not guarantees about every generated use.
V2. Actual isolated dependency environment and public model setup. Record versions, installation provenance, inherited public tools and reused caches honestly; no private references/profile/model copied. Generate real zh-CN and en-US short test recordings from approved test-only text if both advertised; failures remain explicit. Pin dependencies and supported runtime rather than advertise untested hosts/devices.
V3. Integrate with existing voice policy, doctor/first-owner, creative brief, cache and speech stages. Keep owner default Anna unchanged, explicit qwen-public choice, no silent fallback. Enabling public English must not accidentally allow unsupported legacy local English. Bind audio identity to text, language, preset, model/runtime provenance and adapter. Missing/tampered inputs fail before successful artifact publication.
V4. Preserve approval before real project media. A clearly TEST ONLY synthetic fixture can have fixture-only exact receipts. Exercise no receipt, stale text/brief and new valid test receipts. Existing real HTTPX remains unapproved with no media.
V5. Actual public-CLI narrated technical fixture: measure original recordings, fit declared timeline without clipping or time stretching, render real video+audio, FFprobe and full FFmpeg decode. Export complete editable closure, hide original workspace/reviews, import to new location and reuse recordings/preview offline. No private model/profile/reference in package. A changed scene narration needs fresh approval/audio; unchanged scenes remain reusable where supported, original/package bytes preserved. Re-synthesis requires separately installed public voice runtime, not a model bundled into the video.
V6. Targeted tests for validation/language/model identity, timeout/cancellation, error cleanup/cache reuse and portability. Mocked checks labeled, real media runs identified separately. Preserve failed runs. Typecheck/catalog/Skill validation; no broad regression merely to inflate evidence.
V7. Freeze exact source/test/config/docs and relevant evidence before independent review. Active roles: architect Judge covers reliability/security/evidence; separate product/media Judge covers onboarding, public-asset provenance and actual sample frames. Both must resolve blocker/major findings, same judge rechecks repairs. Reviewers never edit candidate or overwrite initial reports. Full continuous listening, perceived voice naturalness and final owner acceptance remain UNVERIFIED if not actually observed.
V8. English onboarding/setup/limits, voice capabilities and canonical Skill match actual tested path. Avoid claiming an OS sandbox from Python offline flags/audit hooks. Clearly distinguish free public preset from private Anna/Chen and an exact voice impersonation. New-user choice remains explicit; script authoring is by current session agent.
V9. Commit/push only source, docs, locks, tests and compact raw reports; exclude binaries, local profiles, references, secrets and runtime artifacts. Verify remote commit, update existing Drive handoff preserving history. Keep raw outputs local and linked, formal script approval pending.

## Responsibilities

Sol runtime implementer owns adapter, setup and source/unit tests. A separate Sol media implementer owns isolated public install, synthetic media fixture and raw evidence. Root owns contract, docs/Skill, frozen candidate, delivery. Astra researches architecture and independently reviews implementation without writing it; a separate Terra judge independently checks product/onboarding and actual frame evidence. Model names follow the user's prior role preferences.

This is a bounded new-user local-speech module, not a new formal public-facing film, cross-platform certification or automatic approval of voice quality. No user-private asset is a dependency of the accepted route.
