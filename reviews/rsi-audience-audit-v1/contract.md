## Mandatory scope

A1. A separate versioned audience-audit request/report/CLI and immutable local evidence packet. Preserve existing quality reports/revision draft payloads/approvals; no new completed runtime records fabricated for legacy media. Context/plan remains authored by session agent, never by the end user. Exact candidate/script/media/font/request hashes, sampled frames and evaluator provenance accompany results.
A2. Measure the actual Showcase Reel DOM after real font/layout readiness using renderer hooks. Use actual text Range rectangles and element/clip bounds, foreground order and declared paint roles; expose mobile-size, overflow and overlap risks. No duplicate approximation HTML. Do not call font size alone a legibility PASS. Occlusion calculations are geometric risks, not proof that alpha pixels or text ink actually obscure content. Embedded source-image/video text remains visually checked/unassessed unless supplied explicit evidence; no imaginary OCR.
A3. Evaluate per-shot/panel source frame selection against exact cue/expectation bindings, including real sourceFrameAt interpolation and panel media/range overrides that bypass parent anchors. Validate expected source-frame windows and cue/source overlap. Unbound, stale or contradictory references refuse or show a finding, never pass silently. Semantics of authored events remain declared until an independent actual-frame review.
A4. Caption display clocks are not verified spoken-word clocks. Reuse optional existing exact audio/transcript/approval-bound speech reports where provided, preserving recognition vs forced-alignment provenance, null ranges, confidence and UNVERIFIED statuses. Without trustworthy timing, report actual speech correspondence unverified. No invented hearing or complete-AV claim. Actual user listening deferral remains.
A5. Two real existing projects (ArtCraft refinement v2 and OpenMAIC O-B) must be exercised: read verified approved manifest/source, sample original candidate frames/audio and compare with current-layout inspection. Historical manifest/movie association is explicitly declared unless authenticated by available producer evidence. Reconstruct exact measured timeline from original audio if necessary; do not silently relabel that as a completed original runtime. Keep original source/script/movie hashes unchanged.
A6. Test browser-backed long captions, narrow labels/overflow, annotation overlap, moving panels, cue edges/independent panel playback, missing timing and stale/tampered inputs. Run targeted tests plus real clips/frames. Preserve initial failures and fix actual implementation bugs. Freeze source/tests before final independent code/logic/evidence review; separately independent actual visual review. Report sample coverage and missing modalities.
A7. Integrate into Skill and documented bounded review/repair process. Findings lead to explicit revision proposals and required fresh approvals, not silent production mutation. Save completed modules, raw reviews, actual results, roadmap and push GitHub; update Google Drive handoff preserving history. No private reference voice/config/model/media upload.

## Interfaces and ownership

Renderer implementer owns DOM hooks, renderer measurement adapter and browser tests. Workflow implementer owns request/expectation contracts, temporal validation, legacy/checkpoint loaders, CLI and report packet. Agree callable API directly before coding. Root owns docs/skill/catalog, real example inputs/integration, roadmap/release. Astra architect independently reviews A1-A7 except actual visual observation; Terra later performs A2/A5/A6 actual frames. Source facts/new script approval not changed. Any current source or report change requires affected reviewer recheck; no majority waiver. This is a bounded improvement, not declaration that the entire product is industry-ready or all audiovisual criteria passed.
