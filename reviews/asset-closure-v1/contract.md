# Bounded story asset integration closure v1

Author: independent architecture/final reviewer. Date: 2026-11-01.

This contract closes the currently separate authored animation, source/research evidence, diagnostic frame renderer and local sound handoff into one durable portable asset package. It does not reopen historical M1–M4 acceptance or certify a finished film. The user's latest bounded integration instruction is the authority. No paid API, publication, target repository execution, full film production, or fabricated listening approval is authorized. Historical UNVERIFIED and final owner audiovisual review remain unchanged.

## Deliverable and interfaces

Add task kind `experimental-story-asset-pack-v1`, with public CLI `story asset-plan --spec <story.json> --root <source-root> --plan <animation.json> --voice <bindings.json> --data <state>`, `story asset-status --task <id> --data <state>`, and `story asset-export --task <id> --data <state> --out <new-directory>`. Existing story/animation commands retain behavior. Internal naming may be adjusted before the first candidate freeze; equivalent behavior is mandatory.

The committed package contains the captured authored story, exact source snapshots, authored animation, complete compiled frame timeline, source-bound research handoff, local audio bindings with portable paths and exact bytes, measured voice handoff, diagnostic SVG frame samples, and an inspectable package manifest. The manifest connects every sample to story shot/frame, authored action and supporting claims/citations, every audio clip to exact current narration and byte hash, and every package file to its content hash. Source URLs/version/line locations and documented-versus-inference classification remain inspectable. Numeric animation parameters and chosen effects are authored illustration choices unless a source actually supports them; the package and rendered frame context must not imply that a cited technical claim proves an arbitrary illustration parameter.

SVG generation uses the existing renderer as a diagnostic visual, with early/middle/late samples of causal scenes and at least one sample per story shot; three samples per shot is acceptable. PNGs may be produced outside the task for independent visual inspection. Such PNGs require a manifest connecting each exact exported SVG hash to PNG hash and rasterization tool/version; PNG review is not inferred from SVG strings or sample states.

## Mandatory acceptance conditions

**AC-01 — One genuine persisted result.** Planning commits the whole package through existing SQLite/CAS task machinery, and returns a stable task identity. A repeated identical request actually reuses the verified task. The status command verifies committed results and lists useful paths, scope and pending review. No output-only JSON script is substituted for this lifecycle.

**AC-02 — Closed inputs and identity.** Task identity binds story/narration/order/timing, captured source byte hashes, authored animation and all rendering semantics, voice declaration/clip bytes, and the implementation/tool versions which materially generate outputs. Identity must not rely on mutable audio/source path names alone. Portable artifact content excludes a dependency on original absolute paths. Any environment-specific execution metadata is clearly separated from reusable content. A stable compiler/source fingerprint is acceptable; no claim of bit-identical PNGs across platforms is required.

**AC-03 — Sound asset truthfulness.** Voice clips require exact current narration declaration, matching story/shot IDs, unique shot bindings, bounded local byte reads, hash verification, one measurable audio stream and positive finite duration. The committed bytes must be the bytes measured, including concurrency protection. Export includes actual audio bytes, not merely a host path. Duration/fit are measured; transcript correctness and voice quality remain caller-declared/unheard. Missing shots and clips longer than estimated available time remain explicit and are never silently stretched, cut or marked approved. Empty bindings are valid but must visibly remain estimate-only/pending. Synthetic audio is explicitly identified as synthetic non-speech in the fixture and evidence.

**AC-04 — Evidence and renderer integration.** A sample is generated from the same persisted story/animation whose sources/research handoff are exported. The viewer can trace shot -> action -> claim -> source snapshot/line, and identify inference/illustration choices. All required inference/synthetic/diagnostic labels are visible without reading hidden SVG metadata. Numeric rule effects, mask roles and arbitrary diagram glyphs are represented honestly. Runtime still supports the existing typed speed/opacity and mask operations without project-ID branches. No automatic source understanding or semantic entailment is claimed.

**AC-05 — Independent portable export.** Export is an exclusively created, complete directory published after staging/verification, never a partially successful package or overwrite of another result. It rejects state/output overlap and unsafe paths as appropriate to existing runtime. A fresh process can status/export a copied committed state after original source/audio locations are unavailable. Exported files suffice to inspect authored inputs, provenance, samples and play supplied audio. No network or original local path is required. Repeated export to a new path preserves identical asset bytes and hashes.

**AC-06 — Deterministic verification and corruption rejection.** Status and export verify task identity, exact output closure, uniqueness/path safety, all CAS artifact bytes and input fingerprints; rederive research/compiled/sample content from stored inputs where deterministic; and validate audio report against its stored byte identity and declaration. Mutating a committed source/audio/sample, swapping another task's artifact, omitting a mandatory file or changing a derived claim must fail clearly rather than produce a success package. Probe need not run on every read if its measured result and generating identity are committed/bound and report derivation is checked within that boundary; document this limitation.

**AC-07 — Real edits invalidate safely.** Actual runs demonstrate a changed source snapshot (with the spec's matching source hash updated), changed animation parameter, changed narration with matching fresh voice declaration, and changed audio bytes each produce a new task identity. Stale narration/clip declarations fail rather than authorize reuse. Earlier successful task/export remains readable and byte-identical. Precise reuse of unaffected subassets is optional; do not claim it without evidence.

**AC-08 — Interrupted work recovers.** A real cancelled/interrupted task attempt, with incomplete work, does not appear as succeeded or leak a published partial directory. Retry through the same public planning entry point can recover to a valid closed result under existing bounded task attempts, while failure/attempt evidence remains inspectable. A unit mock alone is insufficient; use a real process cancellation/termination or the existing runtime's supported deterministic interruption hook with actual durable state. Preserve the failure evidence and show the resulting attempt/state transition.

**AC-09 — Exact proof and regression.** Real REA and rembg packages are built/exported, plus one honestly labeled audio fixture with actual measurable audio. A voice fixture may be a separately labeled synthetic technical test; it need not falsely reuse historical speech for current narration. Run typecheck and focused meaningful regression for story/animation/research/voice/task lifecycle plus new integration adversarial cases. Final candidate manifest hashes relevant source/config/tests, contract, raw commands/logs, state snapshot, exports, visual PNG/raster manifests and actual acceptance evidence. Freeze before independent review; fixes require a new candidate and affected rechecks. Reviewers operate only in isolated scratch state, not the original SQLite files.

## Review allocation and pass rule

Independent Astra architecture/final review covers product scope, lifecycle, portability, invalidation/recovery, provenance integrity and security boundaries. Independent Terra visual review opens actual frozen PNGs and judges the bounded causal readability and label requirements, including speed, opacity and mask examples where present. Root coordinates remaining required evidence checks and reports the exact artifact/version binding. These are feature-closure reviews, not new M1–M4 votes; if root invokes the historical milestone gate, all roles required by that gate must separately report.

PASS requires every mandatory condition supported on the same frozen candidate, no unresolved blocker/major and Terra's actual PNG review. Missing required evidence is UNVERIFIED. Listening/continuous audiovisual quality, final creative quality, automatic repository research, automatic animation selection and finished-film delivery remain outside this bounded closure. They must not be upgraded by test counts or package completeness.

## Implementation sequence

1. Introduce a dedicated asset-pack module using existing capture/compiler/research/voice/task/CAS helpers; avoid a new orchestrator or rewriting historic results.
2. Capture and bind exact inputs once, stage audio bytes for probing, derive deterministic portable payloads and diagnostic frames, commit one strict versioned result.
3. Add read/status/export verification and public CLI with atomic no-overwrite publication.
4. Add a compact end-to-end exercise that generates real packages, edits, tamper checks, portability and interruption/retry evidence; preserve all raw observations.
5. Freeze exact candidate and rasterize its exported SVG samples with a linked manifest; request independent review and fix only with a new freeze.
