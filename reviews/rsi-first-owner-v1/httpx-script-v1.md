## Source and visual references

The GET transcript is a documented example and the planned GitHub crops come from the pinned files below. The two-GET timeline is a teaching illustration. This trial read the source and sent no requests with HTTPX.

- HTTPX is an HTTP client library for Python. [Pinned README lines 16–16](<https://github.com/encode/httpx/blob/b5addb64f0161ff6bfe94c124ef76f6a1fba5254/README.md#L16-L16>).
- The README sends a GET request to www.example.org and shows a response with status 200, a Content-Type header and HTML text. [Pinned README lines 29–38](<https://github.com/encode/httpx/blob/b5addb64f0161ff6bfe94c124ef76f6a1fba5254/README.md#L29-L38>).
- At this commit, the top-level httpx.get delegates to request with method GET; request constructs and uses a Client inside a with block. [Pinned _api.py lines 195–197](<https://github.com/encode/httpx/blob/b5addb64f0161ff6bfe94c124ef76f6a1fba5254/httpx/_api.py#L195-L197>), [Pinned _api.py lines 102–111](<https://github.com/encode/httpx/blob/b5addb64f0161ff6bfe94c124ef76f6a1fba5254/httpx/_api.py#L102-L111>).
- The top-level API does not reuse connections between calls. A Client pools connections and can reuse an underlying TCP connection across requests to the same host. [Pinned Client guide lines 9–13](<https://github.com/encode/httpx/blob/b5addb64f0161ff6bfe94c124ef76f6a1fba5254/docs/advanced/clients.md#L9-L13>).
- The recommended Client context manager cleans up connections when its with block exits; it supports requests through methods such as client.get. [Pinned Client guide lines 34–39](<https://github.com/encode/httpx/blob/b5addb64f0161ff6bfe94c124ef76f6a1fba5254/docs/advanced/clients.md#L34-L39>), [Pinned Client guide lines 51–57](<https://github.com/encode/httpx/blob/b5addb64f0161ff6bfe94c124ef76f6a1fba5254/docs/advanced/clients.md#L51-L57>).
- The Client guide presents the top-level style for simple one-off use and recommends a Client for work beyond that, including repeated requests to the same host. [Pinned Client guide lines 4–13](<https://github.com/encode/httpx/blob/b5addb64f0161ff6bfe94c124ef76f6a1fba5254/docs/advanced/clients.md#L4-L13>), [Pinned README lines 26–32](<https://github.com/encode/httpx/blob/b5addb64f0161ff6bfe94c124ef76f6a1fba5254/README.md#L26-L32>).
