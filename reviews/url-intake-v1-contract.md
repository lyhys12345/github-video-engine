# URL intake v1 acceptance contract

This candidate covers public GitHub URL intake through pinned evidence and an authored editable plan. It uses the existing user delegation and five independent judge roles for a research and planning checkpoint. The earlier milestones and historical audiovisual findings remain separate. No new media is in scope, so the video quality role is inactive.

| ID | Required behavior | Roles |
| --- | --- | --- |
| U1 | A public repository root URL resolves to a full GitHub commit. Bounded documentation is captured through read-only requests and exported with hashes, line counts, source descriptors, pending authoring status, and the next step. | product, evidence |
| U2 | The Story path checks all selected source URLs, hashes, and paths against the stored snapshot and checks exact citation lines before the existing compiler runs. A foreign source fails before the task starts. | reliability, evidence, content_facts |
| U3 | Local status and export preserve original bytes and the task's repository binding. Editing the authored input creates a different task identity. Prior sources and artifacts remain usable. | reliability, evidence |
| U4 | Use independent offline checks, a real public GitHub URL through the authored Story path, and a second materially different live repository to exercise intake and grounded planning. Disclose any narrower scope of the second plan. | product, evidence, content_facts |
| U5 | Reject or explicitly report invalid URL, ref, or document paths, unavailable or rate-limited GitHub reads, missing README, invalid document data, cancellation, existing output conflicts, workspace damage, and foreign Story sources. Avoid overwrites, publication of partial evidence, and execution of repository material. | reliability, security |
| U6 | Artifacts distinguish authored semantics, documented claims and their provenance, inferred or schematic content where used, estimated timing, and pending editorial/final acceptance. No paid service, untrusted execution, or rendering is part of this checkpoint. | product, content_facts, security |
| U7 | The public commands are documented, focused coverage runs in the normal suite, and the frozen candidate binds the source, evidence, and activation policy. Every active role supplies an independent result and the gate retains every failing or unverified finding. | product, reliability, evidence |

The owner remains responsible for final audiovisual acceptance and G6. This checkpoint carries no final film approval.
