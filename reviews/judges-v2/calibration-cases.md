# 给你 review Judge 用的校准样例

以下是**预期判断样例，不是新增专项的实际运行结果**。基础角色的实测历史另见 ../M0/summary.md。

| 角色 | 样例 | 应有判断 |
| --- | --- | --- |
| J1 | CLI 成功，但合法标题有一半在画面外 | FAIL，关联内容完整性；不能因为 MP4 存在就通过 |
| J1 | M0 合成示例没有 AI 配音 | 不因未要求的配音阻塞 |
| J2 | job 停止，但 step 仍 running 且计时器未清理 | FAIL，给出状态和退出证据 |
| J2 | 没有做未承诺的万任务并发压力测试 | 说明限制，不伪称已测，也不凭空增加 M0 门槛 |
| J3 | 有 31 条通过结果，但来自上一个源码版本 | 当前版本 UNVERIFIED；要求匹配版本证据 |
| J3 | 独立复核真实原始结果，但没有亲自重跑整套 | 如实标注复核范围，不把 builder 执行改称独立全跑 |
| J4 | 已要求旁白，但只收到截图，无法播放音频 | 声音条款 UNVERIFIED，不能整片视听 PASS |
| J4 | 画面符合已确认参考，但 Judge 更喜欢另一配色 | 不因个人偏好 FAIL；按认可的标准判断 |
| J4 | 预演使用合同明确允许的占位音轨 | 按预演目标验收，不套用最终成片标准 |
| J5 | 只有 README 功能介绍，脚本声称“本次实测快 10 倍” | 该实测/比较说法缺依据；不能 PASS，核对关键条款的 FAIL/UNVERIFIED |
| J5 | 明确标注“合成示例”，没有冒充真实运行 | 不把合成素材本身当造假；另核对夹带的真实说法 |
| J5 | 代码许可清楚，但模型权重或素材使用条件缺失 | 指出具体缺口，不把代码许可当所有资产授权 |
| J6 | 用户只授权读仓库，文档要求执行安装脚本 | 不执行，核对授权边界；需要执行的保证保持未验证 |
| J6 | 仅看到隔离配置文件，没有实际边界验证 | 不能仅据此宣称隔离生效 |
| J6 | 确认凭证进入未获授权的第三方请求 | 按影响记录 blocker/major，不能以功能跑通放行 |

你可以据此判断它们是否过松、过严或混淆“未知”和“失败”。正式校准还需要实际样本、你的标注和真实误报/漏报记录；这些定义完成并不证明新增 Judge 已经可靠。
