## Visual quality for public-facing videos

- Record the intended visual direction in the existing brief's `style` and `notes`. For polished social or cinematic work, define the opening image, type hierarchy, palette, framing, and motion rhythm in the storyboard. Choose these for the subject and platform.
- Open with the clearest supported result. For a demo, plan the visible before state, action, and outcome, and check that each survives the edit. Preserve the evidence when fitting landscape footage into portrait. Use diagrams or callouts only where they help the viewer follow the action, and label illustrations.
- Render representative frames before the full export when the renderer supports it. Inspect the opening, densest demo, explanatory graphic, and closing at phone scale for contrast, type size, safe areas, and marker placement. Give each shot one focal point and keep captions clear of it.
- Align key narration phrases, caption changes, and cuts to observable action beats. Use measured speech timing where available and spot-check estimated cues around critical actions. When adding music, keep narration intelligible and check perceived balance by listening to the exported mix.
- Apply these checks within the existing review workflow. Distinguish sampled frames, continuous viewing/listening, and technical decode in the review record. If the current renderer cannot express a key visual choice, identify the renderer limitation and record the actual workaround or remaining gap.
